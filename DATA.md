# Data and provenance

This file lists every dataset the Femto recipe downloads, with the stage that uses it, its licence and how it was made.
The registry is `prepare.SOURCES`, and `run.sh` has the exact downloads.

The licences are the ones stated on each dataset's Hugging Face card or upstream repository as of 2026-11. Check them
yourself before redistributing anything. Where a card states no licence, the table says so.

**How the data was made.** We distilled nothing: no larger model was ever prompted to produce Femto's training data.
But several existing datasets in the recipe were themselves generated by larger LLMs. They are marked **LLM** below:
- **Most of them** (marked **LLM**): agentic trajectories, chat, TinyGSM's math programs, and the function-calling sets.
- **Part of the web data** (marked **partly LLM**): ClimbMix.
- **The rest** is human-written text, or programmatic data generated and executed by this code (`exec_traces.py`,
  `tool_sources.py`, `envs.py`, `terminal_tasks.py`).

**Decontamination.** The sources downloaded with `--decontaminate` drop every document that shares a 13-gram with an
eval set (`decontam.py`). The eval sets are CORE, TOOL, BFCL, the QA sets, the weather cities, and the GSM8K, ARC and
MMLU test splits. The pretraining web and code sources were not decontaminated.

## RL environments (`rl.py`, `envs.py`)

- **terminal:** `terminal_tasks.py` generators at training seeds (1000+), minus any task identical to an eval one.
  Programmatic.
- **gsm8k:** GSM8K train, with the python tool.
- **search:** NQ-open, TriviaQA and HotpotQA train questions, minus those of the evals. There is also a tier
  answerable from the prompt, built from SQuAD train (CC-BY-SA-4.0).
- **funcall:** mock APIs whose function schemas come from apigen-80k, minus BFCL's.
- **weather:** templated questions.
- **chat:** requests from SmolTalk's test splits; the reward is overlap with the reference reply (**LLM** references).
- **files:** programmatic.
- **nl2sh:** programmatic templates, minus NL2SH-ALFA's test tasks.

## What this means for the weights

The weights are trained on data under a mix of licences:
- **Permissive:** MIT, Apache-2.0, ODC-By.
- **Share-alike:** CC-BY-SA.
- **Non-commercial upstream:** ClimbMix, whose NVIDIA original is CC-BY-NC-4.0.

They also carry text generated by models whose own terms may restrict use, such as Llama 3.1 for SmolTalk and the
agent models behind the terminal trajectories. If you plan to use Femto commercially, check those terms first.
